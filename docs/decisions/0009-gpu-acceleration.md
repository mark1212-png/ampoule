# 0009. GPU acceleration is a goal, not a 1.0 blocker

- Status: Accepted
- Date: 2026-10-06

## Context

Most development work runs fine on a software renderer; desktop users notice the difference.

## Decision

Treat 3D acceleration as a post-1.0 research track, starting with Linux (Venus to MoltenVK).

## Consequences

1.0 Windows and Linux guests use a display-only framebuffer.
