# 0016. Project name: Ampoule

- Status: Accepted
- Date: 2026-10-06

## Context

The working name mVM collides with `tinylabscom/mvm`, an active Rust microVM project on Hypervisor.framework that also publishes `mvm-*` crates.

## Decision

Rename to Ampoule: a sealed glass vial (isolation, glass). Free on Homebrew and crates.io as of 2026-10-06.

## Consequences

A trademark search is still needed before 1.0.
