# 0003. Minimum host macOS 26

- Status: Accepted
- Date: 2026-10-06

## Context

macOS 26 introduced Liquid Glass and newer Virtualization.framework APIs.

## Decision

Require macOS 26 or later on Apple Silicon.

## Consequences

No fallback UI code. Users on older macOS versions cannot run Ampoule.
