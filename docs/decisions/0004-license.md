# 0004. License: Apache-2.0 with DCO

- Status: Accepted
- Date: 2026-10-06

## Context

The project should be easy to adopt and contribute to, including by companies, and must be App Store-compatible.

## Decision

License all code under Apache-2.0. Contributors certify the Developer Certificate of Origin with `git commit -s`.

## Consequences

No GPL code may be linked into shipped binaries. Dependencies must be permissively licensed.
