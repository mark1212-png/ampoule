# 0018. AI-assisted development workflow

- Status: Accepted
- Date: 2026-10-06

## Context

Most implementation is done with AI agents. Authorship must be honest and visible.

## Decision

The author designs, decides and reviews; AI agents implement. Decisions get records here; every change goes through a PR using the template; AI-written commits carry a Co-Authored-By trailer; corrections to AI output are logged in docs/ai-review.

## Consequences

Some extra process on every change. The git history and review log become evidence of how the project was built.
