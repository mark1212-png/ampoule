# 0008. Windows install: bring your own ISO or guided download

- Status: Accepted
- Date: 2026-10-06

## Context

Some users already have an ISO; others want a guided path.

## Decision

Offer both. Both paths generate `autounattend.xml` and install the guest agent automatically.

## Consequences

We never redistribute Windows images.
